About CodeImpact

CodeImpact is a front-end prototype that explores how a change in one JavaScript file may affect other files in a project.

  • Upload JavaScript files or a ZIP archive.
  • Detect basic local imports and dependencies.
  • Compare a current file with a proposed version.
  • View a dependency graph and export a text report.

Analysis runs in your browser. The results are heuristic and should not replace tests, code review, or a real parser.
